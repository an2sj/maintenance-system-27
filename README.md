# نظام إدارة الصيانة وأوامر العمل

**مستشفى الأمير محمد بن ناصر | تجمع جازان الصحي**

تطبيق ويب سحابي يعمل 24/7 لإدارة أوامر العمل واستلام بلاغات الصيانة عبر رمز QR، متاح من الآيباد والجوال من أي مكان.

## المزايا

- **لوحة تحكم محمية بكلمة مرور**: كروت إحصائيات، جدول البلاغات، بحث وتصفية، طباعة وحذف.
- **إنشاء أمر عمل**: الاسم، التواصل، الموقع/المبنى (T5, T6, T1, المرافق)، الوحدة، نوع الصيانة والمشكلة، الأولوية، الفني، وصف المشكلة، مع **رفع صور/فيديو**.
- **واجهة ثنائية اللغة** عربية/إنجليزية (زر تبديل في أعلى الصفحة) مع هوية تجمع جازان الصحي وشعاره.
- **تعديل أمر العمل** بعد إنشائه وتتبع رقم مرجعي فريد `R…` لكل طلب.
- **الطلبات الواردة (QR)**: البلاغات المرفوعة عبر الرمز تصل لقسم التدقيق ثم تُعتمد أو تُرفض.
- **رمز QR لكل أمر** + **ملصق QR عام** للطباعة والتعلق في الأقسام.
- **طباعة أمر العمل بالهيدر الرسمي** لـ(تجمع جازان الصحي) مع حقول التوقيع.
- **التقرير الشهري القابل للطباعة** مع إحصائيات وتفاصيل.
- **صفحة تتبع عامة** تفتح بمسح رمز QR.
- قاعدة بيانات **SQLite** محفوظة على قرص دائم (لا تفقد عند إعادة النشر).

## التشغيل المحلي

```bash
pip install -r requirements.txt
python main.py
```

ثم افتح http://localhost:8000

## النشر على Render (موقع رسمي عام 24/7)

### 1) ارفع الكود إلى GitHub
1. أنشئ مستودعاً جديداً على [github.com](https://github.com) (لا تضع علامة أي ملف تلقائي).
2. ارفع ملفات هذا المجلد: New → Upload files (أو عبر Git).

### 2) أنشئ خدمة ويب على Render
1. سجّل في [render.com](https://render.com) واربط حساب GitHub.
2. **New → Web Service** ← اختر مستودعك.
3. اترك القيم الافتراضية (ستقرأ تلقائياً من `render.yaml`):
   - Build Command: `python -m pip install -r requirements.txt`
   - Start Command: `uvicorn main:app --host 0.0.0.0 --port $PORT`
4. **اضبط متغيرات البيئة** (Environment → Environment Variables):

   | المتغير | القيمة |
   |---|---|
   | `DASHBOARD_PASSWORD` | كلمة مرور قوية للوحة التحكم (أمر ضروري) |
   | `PUBLIC_BASE_URL` | رابط موقعك بعد النشر، مثال: `https://xxx.onrender.com` |
   | `COOKIE_SECURE` | `1` |

   > ملف `render.yaml` يضيف قرصاً دائماً (`/data`) تلقائياً، ويستخدمه التطبيق لقاعدة البيانات، لذا بياناتك تبقى محفوظة بين إعادة النشر.

5. اضغط **Apply / Deploy** وانتظر اكتمال البناء (دقيقتان تقريباً).
6. ستحصل على رابط عام مثل `https://xxx.onrender.com`.

### 3) عند أول تشغيل
- ادخل إلى الرابط عموماً: **`/report`** صفحة البلاغ (تُفتح بالمجان بدون كلمة مرور).
- **`/poster`** لطباعة ملصق QR وتوزيعه في الأقسام.
- **`/`** لوحة التحكم (تتطلب كلمة المرور `DASHBOARD_PASSWORD`).

## الصفحات

| الرابط | الوصف | الحماية |
|---|---|---|
| `/` | لوحة المتابعة والإحصائيات | كلمة مرور |
| `/orders/new` | إنشاء أمر عمل | كلمة مرور |
| `/incoming` | تدقيق الطلبات الواردة | كلمة مرور |
| `/monthly` | التقرير الشهري | كلمة مرور |
| `/poster` | ملصق QR للطباعة | كلمة مرور |
| `/report` | بلاغ عام (بمسح QR) | مجاني |
| `/orders/{id}/print` | طباعة بالهيدر الرسمي | كلمة مرور |
| `/track/{token}` | تتبع عام | مجاني |
| `/api/docs` | توثيق الواجهة البرمجية | كلمة مرور |

## متغيرات البيئة

| المتغير | الوصف | الافتراضي |
|---|---|---|
| `PORT` | المنفذ (تحدده المنصة) | 8000 |
| `DASHBOARD_PASSWORD` | كلمة مرور اللوحة (فارغ = بدون حماية) | - |
| `PUBLIC_BASE_URL` | الرابط العام لرموز QR خلف الـ Proxy | من الطلب |
| `DB_PATH` | مسار ملف SQLite | `/data` (على Render مجاناً) |
| `APP_TIMEZONE` | المنطقة الزمنية | Asia/Riyadh |
| `COOKIE_SECURE` | تفعيل كوكيز HTTPS | 1 |

## ملاحظات الأمان
- **احرص دائماً** على تعيين `DASHBOARD_PASSWORD`.
- الصفحات العامة (`/report`, `/track`, `/poster-qr`) لا تكشف بيانات حساسة.
- قاعدة البيانات محفوظة على قرص ثابت، لكن يُنصح بعمل نسخة احتياطية دورية من ملف `maintenance.db`.
